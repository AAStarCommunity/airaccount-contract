## 跟帖 1:开发者快速上手代码片段(发在主消息下面 thread)

````
🚀 **3 分钟集成示例(TypeScript)**

```typescript
import { AirAccount, SuperPaymaster } from '@aastar/sdk';

// Step 1: WebAuthn 注册 + 部署 AirAccount(Sepolia)
const account = await AirAccount.create({
  provider: 'webauthn',
  chain: 'sepolia',
});
console.log('Address:', account.address);

// Step 2: 发起 gasless 交易(用 xPNTs 付 gas)
const tx = await SuperPaymaster.sendGasless({
  account,
  to: '0x...',           // 目标合约
  data: '0x...',         // calldata
  paymentToken: 'xPNTs', // 社区代币替代 ETH
});

console.log('Tx hash:', tx.hash);
```

SDK 包(刚刚 sync v0.17.2-beta.2 ABIs):
`pnpm add @aastar/sdk@^0.18.0`

⚠️ 用 **pnpm**,不要用 npm/yarn
⚠️ Web3 库用 **viem**,不要用 ethers.js
````

## 跟帖 2:技术细节(发给关心架构的开发者)

```
🔧 **技术亮点 — Diamond-lite 架构**

AirAccount v7 突破了 EIP-170 24KB 限制,但**零能力损失**:

• 主合约:22,697 B(原本 27,975 B 超限)
• Agent + governance 函数通过 fallback + delegatecall 走 AirAccountExtension
• Storage 字节级一致(共享 AAStarAgentStorageLayout)
• SDK 用 merged ABI(`abi/AAStarAirAccountV7.full.json`)— 集成方完全无感

⚠️ 关键提示:Raw `out/AAStarAirAccountV7.sol` ABI 缺 fallback-routed 函数。
集成时必须用 `abi/AAStarAirAccountV7.full.json`(已包含在 SDK 中)。

详见: <https://github.com/AAStarCommunity/airaccount-contract/blob/main/docs/2026-05-26-diamond-lite-migration-impact.md>
```
