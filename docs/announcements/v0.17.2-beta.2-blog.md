## ⭐ 8 大核心能力(v0.17.x 累积)

| # | 能力 | 你能用它做什么 |
|---|------|---------------|
| 1 | **WebAuthn / Passkey 登录** | 指纹/面部/PIN 即账户,无密码无助记词。P-256 直接通过 EIP-7212 链上验证 |
| 2 | **Tiered 多签验证** | 单一 WebAuthn(<$100) → 双因子(<$1K) → 多签共识(>$1K),链上强制金额上限 |
| 3 | **Session Key + Agent 系统** | 单一 `SessionKeyValidator` 同时支持 classic session(单 target)和 agent 模式(velocity rate / callTargets / selectorAllowlist / P256 passkey)。Agent 永远不持有 owner 权,边界是账户不是 key |
| 4 | **ERC-8004 Agent 经济** | 官方 Identity / Reputation / Validation registries + factory 白名单。链上 agent 身份与声誉 |
| 5 | **Social Recovery(3-2-48h)** | 3 监护人,2-of-3 阈值,48 小时时间锁。cancelRecovery 需 2-of-3 监护人投票(非 owner)|
| 6 | **ForceExit 紧急提取** | L2→L1 桥接提款(Optimism / Arbitrum)。v0.17.2-beta.2 新增 stale-guardian 防护 |
| 7 | **EIP-7702 EOA 升级** | `AirAccountDelegate` 让现有 EOA 一笔 type-4 tx 获得 AirAccount 全部能力,无需迁移资产 |
| 8 | **ERC-4337 v0.7 + ERC-7579 模块化** | 标准 paymaster 接口、validator/executor/hook 三类模块按需装卸,SuperPaymaster 无缝接入 |

### ⚙️ Diamond-lite 架构

突破 EIP-170 24,576 字节限制,**零能力损失**:

- 主合约 runtime bytecode: 22,697 B(原本 27,975 B 超限)
- Agent + governance 函数通过 `fallback` + `delegatecall` 走 `AirAccountExtension`
- Storage 字节级一致(共享 `AAStarAgentStorageLayout`)
- SDK 用合并 ABI([`abi/AAStarAirAccountV7.full.json`](https://github.com/AAStarCommunity/airaccount-contract/blob/main/abi/AAStarAirAccountV7.full.json)),集成方完全无感

详见:[`docs/2026-05-26-diamond-lite-migration-impact.md`](https://github.com/AAStarCommunity/airaccount-contract/blob/main/docs/2026-05-26-diamond-lite-migration-impact.md)

## 🛠 开发者接入路径(5 步)

### 步骤 1:用 `@aastar/sdk` (v0.18+) 创建账户

```typescript
import { AirAccount } from '@aastar/sdk';

// WebAuthn 注册 → TEE 内创建 P-256 密钥 → 部署 AirAccount
const account = await AirAccount.create({
  provider: 'webauthn',
  chain: 'sepolia',
});

console.log('Account address:', account.address);
console.log('Owner (P-256 from WebAuthn):', account.owner);
```

11 个合约的 ABI + Sepolia 地址已 sync 到 `@aastar/core@0.18.x` 候选(SDK PR #42 评审中,待合并)。

### 步骤 2:接入 SuperPaymaster — gasless 交易

```typescript
import { SuperPaymaster } from '@aastar/sdk';

const tx = await SuperPaymaster.sendGasless({
  account,
  to: contractAddress,
  data: callData,
  paymentToken: 'xPNTs', // 用社区积分(xPNTs)替代 ETH 付 gas
});

console.log('Tx hash:', tx.hash);
```

SuperPaymaster `validatePaymasterUserOp` 已识别 AirAccount Factory `0xc6c7…BaeE9`(待 Paymaster 团队最终配置确认)。

### 步骤 3:启用 Session Key — 让 dApp/Agent 受限代签

```typescript
// 给 dApp 一个 1 小时、单合约、单 selector、最多 0.1 ETH/h 的 session key
await account.installModule({
  type: 'session-key',
  policy: {
    duration: 3600,
    callTargets: [dappContract],
    selectorAllowlist: ['0xa9059cbb'], // transfer(address,uint256)
    velocity: {
      window: 3600,
      max: parseEther('0.1'),
    },
  },
});

// dApp 拿到 session key 后,在 1 小时内可代签符合 policy 的 UserOp
// 超时 / 超额 / 越界 — 链上自动拒绝
```

### 步骤 4:启用 Social Recovery — 设置 3 个监护人

```typescript
await account.setGuardians([guardianA, guardianB, guardianC]);

// 场景:用户丢失设备
// 1. 2 个监护人调用 proposeRecovery(newOwner)
// 2. 48 小时时间锁开始
// 3. 时间锁结束后,executeRecovery → newOwner 接管账户
// 4. 老监护人若变动,会被 stale-guardian 检查拒绝(v0.17.2-beta.2 新增)
```

### 步骤 5(可选):安装 ForceExit — 极端情况下逃逸到 L1

```typescript
await account.installModule({
  type: 'force-exit',
  destinationL1: ownerEOA, // L2 桥过去的目的地
  amount: parseEther('0.5'),
});

// 场景:L2 sequencer 故障 / 监护人被胁迫 / 合约升级失败
// 监护人 2-of-3 投票 → L1 bridge 提取 → ownerEOA 拿回资金
```

## 🔐 安全:8 轮 Codex 对抗审计 + David Human Review

修复的 H/M findings:

- **BLS infinity-point bypass**(per-UO + final aggregate 双检查)
- **Aggregator unbound-to-userOps**(从 `userOps[i].signature` 重算,避免 signature reuse)
- **Weighted-sig token tier mismatch**(传 resolved algId 到 `_checkTokenGuard`)
- **EIP-7702 delegate ERC20 inline check**(原生 `transfer`/`approve` selector,不再依赖 EIP-7579 fallback)
- **ForceExit stale-guardian**(approve 时强制 guardian freshness 检查 — v0.17.2-beta.2)
- **AgentRegistry factory-provenance**(白名单 — 防止恶意 factory 注入)
- **`bindFactory`** deployer-only ACL(防止任意账户绑定)
- **5-arg shim confused-deputy**(关闭老接口的权限边界滑动)

**成绩单**:
- Forge unit tests: **674 / 0 / 0**
- Sepolia 链上 E2E: **79 / 79 PASS**
- Etherscan verified: **11 / 11**
- Gas usage: 部分关键路径 vs YetAnotherAA 节省 ~50%(见 `docs/gas-analysis.md`)
