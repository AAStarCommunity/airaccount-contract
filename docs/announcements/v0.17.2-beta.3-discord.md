## 主消息

```
🛠 **AirAccount v0.17.2-beta.3 — Sepolia**

代码质量 + 可观测性版本。**无行为变更** — 现有账户不受影响，无需迁移。

━━━━━━━━━━━━━━━━━━━━━━━━━━
🔢 **VERSION 常量(链上版本检测)**

所有主要合约现在暴露 `string public constant VERSION`:
```
account.ACCOUNT_VERSION()        → "0.17.2"
factory.FACTORY_VERSION()        → "0.17.2"
ForceExitModule.MODULE_VERSION() → "0.17.2"
SessionKeyValidator.MODULE_VERSION() → "0.17.2"
```
SDK 可以直接链上检测合约版本,无需维护版本映射表。

━━━━━━━━━━━━━━━━━━━━━━━━━━
🏗 **AlgTierLib — algId→tier 映射单一来源**

从 `AAStarAirAccountBase` 和 `AAStarGlobalGuard` 提取了独立维护的 `_algTier()` 逻辑到 `src/utils/AlgTierLib.sol`(内部 library,编译时内联,零 gas 额外开销)。

之前:两份独立实现,NatSpec 说"必须保持同步"。
之后:一个 library,一个地方修改,审计员只需看一处。

━━━━━━━━━━━━━━━━━━━━━━━━━━
🚨 **Factory custom errors**

`AAStarAirAccountFactoryV7` + `AAStarGlobalGuard` 所有 `require(string)` 全部替换为 typed custom errors:
`GuardiansRequired`, `GuardiansMustBeDistinct`, `DailyLimitRequired`, `AgentKeyRequired` 等共 16 个。

**SDK 影响**: 如果你在 catch 里匹配字符串错误消息,需要改用 selector 匹配。

━━━━━━━━━━━━━━━━━━━━━━━━━━
🛡 **ForceExit 安装加固**

`ForceExitModule.onInstall` 现在检查 `guardians(0)` 返回非零地址,安装时拒绝不兼容账户(`IncompatibleAccount` error),防止"僵尸模块"(装上但永远无法 approve)。

━━━━━━━━━━━━━━━━━━━━━━━━━━
⚡ **Gas 优化 — Assembly popcount**

`_popcount()`(AAStarAirAccountBase)和 `_countBits()`(ForceExitModule)改用并行位运算(Hamming weight)。3-guardian bitmap 约减少 5-8x 操作码。语义完全等价。

━━━━━━━━━━━━━━━━━━━━━━━━━━

## 跟帖:SDK 迁移指引(发给开发者)

```
📦 **beta.3 → SDK 迁移清单**

1️⃣ **更新 ABI**
```
# 从 repo 同步最新 ABI
abi/AAStarAirAccountV7.full.json  # 64 functions (was 63)
```
pnpm add @aastar/core@latest  # 等 SDK 同步后

2️⃣ **Factory 错误处理 — 改用 selector**
```typescript
// ❌ beta.2 (string match)
catch (e) { if (e.message.includes("Guardians required")) ... }

// ✅ beta.3 (selector match)
import { GuardiansRequired } from '@aastar/core/errors';
catch (e) { if (isContractError(e, GuardiansRequired)) ... }
```

3️⃣ **可选:读取链上版本**
```typescript
const version = await account.read.ACCOUNT_VERSION();
// → "0.17.2"
```

4️⃣ **ForceExit 安装 — 无变化**
正常 AirAccount 账户(`guardians(0)` 非零)安装无感知。
只有非标准合约(无 guardian getter)会遇到 `IncompatibleAccount` error。
```
