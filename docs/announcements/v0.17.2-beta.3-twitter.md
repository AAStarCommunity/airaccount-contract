```
New in beta.3: every AirAccount contract now exposes an on-chain VERSION string.

account.ACCOUNT_VERSION()    → "0.17.2"
factory.FACTORY_VERSION()    → "0.17.2"
ForceExitModule.MODULE_VERSION() → "0.17.2"
SessionKeyValidator.MODULE_VERSION() → "0.17.2"

SDK can detect contract version without off-chain config. No more guess-which-deploy.
```

**Tweet 3/4** — AlgTierLib
```
Internals matter for security.

Before beta.3: two independent copies of the algId→tier mapping
(AAStarAirAccountBase + AAStarGlobalGuard). Comment: "must stay in sync."

After beta.3: one AlgTierLib. Both contracts delegate to it.
Add a new algId? One file. No drift. No audit finding.
```
